Load a CSV to run the audit.

Required columns

experiment_id, camera_model, sensor_type, fps, exposure_ms, readout_ms, distance_m, wavelength_nm, frequency_hz, duty_cycle, modulation_depth, phase_spread_deg, screen_type, irradiance_w_m2, visible_lux, ssim, psnr_db, banding_energy, delta_e, viewer_impact_score, notes

Interpretation

Measured degradation is derived as 100 × (1 − SSIM) when SSIM is available. This is only one metric; PSNR, banding energy and color error should be reported separately in the paper.

Model MAE compares that measured degradation with the simplified simulator prediction. A large MAE is useful: it tells us which physics or camera-processing terms the model is missing.
